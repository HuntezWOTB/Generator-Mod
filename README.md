# 🚀 Generator-Mod
v 1.0 (BETA)

**Automatically reveals all tanks in the WOT BLITZ research tree.**  
Works with XML/YAML and DVPL (LZ4). Supports DLC packs, 3 modes, 6 languages.

---

## ⚡ Quick Start

1. Install **Python 3.8+** (download from [python.org](https://python.org)).
2. Run **`autoinstall_modules.bat`** – it will install all dependencies.
3. Run **`start_program.bat`** – the GUI will open.

> 💡 If `.bat` files are missing, install manually:
> ```bash
> pip install -r requirements.txt
> python gui.py
> ```

---

## ⚠️ Important: Micro‑updates and DLC

When the game receives micro‑updates (new vehicles), **it is recommended to keep the "Modify DLC files" option enabled** – this ensures that new DLC tanks are also displayed in the research tree.  
For details, see the full documentation.
