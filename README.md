# 🚀 Generator-Mod

**Automation to display all vehicles in the research tree of WOT BLITZ.**  
Works with all file formats (original `xml`/`yaml` and packed `dvpl`).

## ⚡ Quick Start

1. Install Python 3.8+.
2. Run `autoinstall_modules.bat` to install dependencies.
3. Run `start_program.bat` to launch.

For detailed instructions, see the full documentation.
